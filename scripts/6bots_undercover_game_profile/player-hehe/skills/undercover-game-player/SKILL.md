# 谁是卧底 · 玩家技能

## 第一步永远是判断任务类型

判错类型 = 格式错 = 这一轮作废。先看这张表：

| 特征 | 类型 | 我要输出 |
| --- | --- | --- |
| 正文说"你是 N 号玩家，你的词语是【X】…请只输出一句话，描述你的词语" | **发言节点** | 一句话，≤25 字 |
| 正文说"现在是第 N 轮投票…只输出票号" | **投票节点** | 只有「我投N号」，≤10 字，无理由 |
| 正文说"你在第 N 轮被投出局了…请说一句遗言" | **遗言任务** | 一句话，≤20 字 |
| 正文说"本轮没有人出局…下一轮由你第一个发言" | **预备任务** | 一句话，≤15 字，表示准备好了 |
| 其他 | 兜底 | 按最接近的一种输出，**绝不空回复** |

**每一种我都只需要回一句话，不需要调用任何工具。** 发言和投票是协作节点，直接把那句话作为最终回复；遗言和预备是主持人派的任务，同样正常回复即可。

**收到任务就立刻回，不要"等一会儿再回"。** 我的每一条回执都会让服务端往主持人的会话里
灌一条状态更新，而那条灌入会打断主持人当时正在跑的活。回执早一点晚一点它都躲不开，但拖着
不回只会让撞上的窗口更难预测。想好了就回，一句话的事。

**每一轮的开场和开投都由主持人说，不会派给我。** 我只会收到上表里那四种任务。

## 发言：怎么写

任务里给我两样东西：**我的词**，和**本轮在我之前所有人的原话**（在 `[Upstream Outputs]` 里）。历史轮次的发言在 `[Input]` 里。

### 先量一下钝度

**我不知道自己是不是卧底。** 所以每一句话都要按"万一我是卧底"来写——一句只有我的词才成立的话，等于自己举手。

任务正文里会给出**本轮钝度 N**，这是一把能自己算的尺子：

> 把写好的这句话原样念给一个没参加游戏的人，他能列出至少 N 样符合的东西吗？

列不出来就是太具体了，重写得更钝。举个真实的翻车例子：平民词是剃须刀、卧底词是指甲钳，卧底第一轮说了「手指端长了就剪短，随身带的金属件」——局外人只能想到指甲钳，N=1。而那一轮要求 N=4。它当场就被投出去了，整局只玩了一轮。

改法是往上抽一层：「长了不处理会不舒服」——指甲、头发、胡子、杂草、宠物毛都成立，N≥5，合格，而且**对剃须刀和指甲钳一样成立**，这才是安全的说法。

### 再看前面的人

1. **他们到了什么钝度？我不能比他们更锐利。** 换个角度可以，但要换成同样钝的角度。
2. **绝对不要"补一个别人没覆盖的角度"。** 没被覆盖的角度往往正是只有我的词才成立的角度——如果我是卧底，那一刀是砍向自己的。
3. **有没有人的描述和我的词明显对不上？** 记下来，但**不要写进发言里**——发言只描述词，怀疑留到投票。
4. 我是第一个发言的话没有参照，本轮的钝度由我定，宁可更钝。

硬约束：

- 一句话，**不超过 25 个字**。
- **满足任务正文给的本轮钝度 N。** 这条和字数一样是硬约束，不是建议。
- **不得说出我的词本身，不得说出词里连续的两个字，也不得把词拆散了在句子里说全**；不得用拼音、英文、谐音。任务正文里会把这几条按我的词展开写清楚，照着做。
- 不提身份、卧底、平民、轮次、规则、票数。
- 不点评其他玩家，不说"我同意 X 号"式的空话（可以顺着方向说，但必须真的在描述我的词）。
- 只输出那一句话本身：没有编号、没有引号、没有"我的发言："、没有 JSON、没有解释。

## 投票：怎么写

**唯一的判断依据是 `[Input]` 里所有人全部历史轮次的发言原话**，逐字可查。所有人同时投，我看不到别人的票，也拿不到任何人的投票理由——因为谁都不写理由。

判断口径：

- 值得投的：两轮之间自相矛盾的；描述指向另一件明显不同的东西的；一直附和别人没有任何自己内容的。
- 不值得投的：只是话少、或者风格和我不一样、或者这一轮说得比较钝——钝是规则要求的。
- 我的词和大多数人的描述对不上时，这是重要信号——但不代表他们是卧底，也可能是我。照常按发言证据投。

格式**只有票号，没有理由**：

```
我投4号
```

- 只输出「我投N号」，N 是阿拉伯数字。不写理由、不引用别人的话、不解释、不加前缀。
- 整条不超过 10 个字。不能投自己，不能投已出局的人。
- 确实看不出来就只输出「我弃权」，同样不写原因。

**为什么不写理由**：一条理由本质上是"拿我的词去比对他的话"的结果。写「他说需要通电，跟我理解的不一样」，等于把我那个词的一个属性广播给全场——如果我是卧底，这一句比发言还致命。所以推理全部留在心里，只交票号。

投票这一步没有我的风格发挥空间，格式是死的。**个性体现在投给谁，不体现在怎么写。**

## 遗言与预备

- 遗言：一句不超过 20 字的话，符合我的性格，可以喊冤也可以放狠话。不说出我的词，不说自己是不是卧底，不指认任何人。**这条是公开的，主持人来不及帮我遮，说漏了就真漏了。**
- 预备：一句不超过 15 字的话，表示准备好了。不提词语、身份或任何推理。

## 绝对不做

- 不泄露我的词（包括影射字数、字形、拼音）。
- 不宣称知道自己的身份——我确实不知道。
- 不冒充主持人宣布任何结果。
- 不编造其他玩家说过的话；引用发言必须用原文。
- 不主动往群里发消息，不用 `bcs session chat` / `bcs chat`，不建群、不加成员。
- 不查询群历史、其他玩家或运行状态。
- **不空回复、不反问、不说"收到"**——空回复会让整轮作废。

## 输出前自检

1. 有没有说出我的词、词里连续的两个字，或者把词的每个字都散在句子里？有没有拼音、英文、谐音？
2. 字数超了吗？
3. 发言：达到本轮钝度 N 了吗——局外人真的能列出 N 样符合的东西吗？
4. 格式对吗（发言 = 纯一句话；投票 = 只有「我投N号」，没有理由）？
5. 有没有多余的前缀、引号、编号、解释？
6. 发言里有没有混进对别人的点评或身份话题？
