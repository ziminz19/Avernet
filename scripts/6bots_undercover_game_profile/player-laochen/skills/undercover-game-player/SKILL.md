# 谁是卧底 · 玩家技能

## 第一步永远是判断任务类型

判错类型 = 格式错 = 这一轮作废。先看这张表：

| 特征 | 类型 | 我要输出 |
| --- | --- | --- |
| 正文说"你是 N 号玩家，你的词语是【X】…请只输出一句话，描述你的词语" | **发言节点** | 一句话，≤25 字 |
| 正文说"现在是第 N 轮投票…以「我投N号」开头" | **投票节点** | 一句话，≤40 字，以「我投N号」开头 |
| 正文说"你在第 N 轮被投出局了…请说一句遗言" | **遗言任务** | 一句话，≤20 字 |
| 正文说"本轮没有人出局…下一轮由你第一个发言" | **预备任务** | 一句话，≤15 字，表示准备好了 |
| 其他 | 兜底 | 按最接近的一种输出，**绝不空回复** |

**四种情况我都只需要回一句话，不需要调用任何工具。** 发言和投票是协作节点，直接把那句话作为最终回复；遗言和预备是主持人派的任务，同样正常回复即可。

## 发言：怎么写

任务里给我两样东西：**我的词**，和**本轮在我之前所有人的原话**（在 `[Upstream Outputs]` 里）。历史轮次的发言在 `[Input]` 里。

写之前想清楚三件事：

1. **前面的人给了什么方向？** 我这一句要在他们没覆盖的角度上补一刀，不要重复。
2. **我的描述有多准？** 太准会送情报也会暴露自己，太糊会吃票。第一轮宽一点，越往后越可以收窄。
3. **有没有人的描述和我的词明显对不上？** 记下来，但**不要写进发言里**——发言只描述词，怀疑留到投票。

硬约束：

- 一句话，**不超过 25 个字**。
- **不得说出我的词本身，不得说出词里连续的两个字，也不得把词拆散了在句子里说全**；不得用拼音、英文、谐音。任务正文里会把这几条按我的词展开写清楚，照着做。
- 不提身份、卧底、平民、轮次、规则、票数。
- 不点评其他玩家，不说"我同意 X 号"式的空话（可以顺着方向说，但必须真的在描述我的词）。
- 只输出那一句话本身：没有编号、没有引号、没有"我的发言："、没有 JSON、没有解释。

## 投票：怎么写

任务里给我：**我的词**、全场名单、可以投的人、以及 `[Input]` 里逐字可查的全部发言。所有人同时投，我看不到别人的票。

判断口径：

- 值得投的：两轮之间自相矛盾的；描述指向另一件明显不同的东西的；一直附和别人没有任何自己内容的。
- 不值得投的：只是话少、或者风格和我不一样。
- 我的词和大多数人的描述对不上时，这是重要信号——但不代表他们是卧底，也可能是我。照常按发言证据投。

格式：

```
我投4号，他说「需要通电」，跟我理解的完全不是一回事。
```

- **必须以「我投N号」开头**，N 是阿拉伯数字。
- 后面接一句我自己口吻的理由，**理由里必须引用被投者说过的一句原话**。引用别人的话既让理由有据可查，也让我不必提到自己的词。
- 整句不超过 40 个字。不能投自己，不能投已出局的人。
- 确实看不出来就写「我弃权」加一句原因。
- 泄词的红线和发言完全一样。

## 遗言与预备

- 遗言：一句不超过 20 字的话，符合我的性格，可以喊冤也可以放狠话。不说出我的词，不说自己是不是卧底，不指认任何人。**这条是公开的，主持人来不及帮我遮，说漏了就真漏了。**
- 预备：一句不超过 15 字的话，表示准备好了。不提词语、身份或任何推理。

## 绝对不做

- 不泄露我的词（包括影射字数、字形、拼音）。
- 不宣称知道自己的身份——我确实不知道。
- 不冒充主持人宣布任何结果。
- 不编造其他玩家说过的话；引用发言必须用原文。
- 不主动往群里发消息，不用 `bcs session chat` / `bcs chat`，不建群、不加成员。
- 不查询群历史、其他玩家或运行状态。
- **不空回复、不反问、不说"收到"**——空回复会让整轮作废。

## 输出前自检

1. 有没有说出我的词、词里连续的两个字，或者把词的每个字都散在句子里？有没有拼音、英文、谐音？
2. 字数超了吗？
3. 格式对吗（发言 = 纯一句话；投票 = 以「我投N号」开头且引用了原话）？
4. 有没有多余的前缀、引号、编号、解释？
5. 发言里有没有混进对别人的点评或身份话题？
