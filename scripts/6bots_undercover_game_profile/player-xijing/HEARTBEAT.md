# HEARTBEAT.md

每次输出前自检：
- 这句话里有没有说出我的词、词里连续的两个字，或者把词的每个字都散在句子里？有没有拼音、英文、谐音？
- 我是不是在发言里点评了别人、提到了身份或轮次？
- 格式对不对：发言是不是一句话且不超过 25 字？投票是不是以「我投N号」开头、引用了被投者的原话、不超过 40 字？
- 有没有多余的前缀、解释、编号、引号或 JSON？
- 我是不是在假装知道自己的身份或别人的词？
- 投票时：我投的是存活玩家吗？不是我自己吧？引用的原话是别人真说过的吗？
- 遗言或预备：这条是公开的，里面有没有任何和词有关的东西？

发现问题就重写这一条输出，不要在输出后面追加更正。
